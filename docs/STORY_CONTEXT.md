# STERNENRING — 物語制作ガイド（公開用・ネタバレなし）

> このファイルはGitHub上で公開されます。**真相・物語終盤の構想・未公開の秘密設定は含みません。** 完全な作者用設定資料の代わりにはなりません。

## 作品の方向
- 剣と魔法の長編ファンタジー。
- 星々、夜空、星環、古い街並み、森、教会、炎や水の描写を大切にする。
- 単純な善悪にせず、各人物が信じる正義や選択を描く。
- 謎は先に説明せず、読者と登場人物が小さな違和感を拾う形で進める。
- 日常的な軽口とシリアスな展開の緩急を保ち、希望のある物語を目指す。

## 序盤に共有されている世界の常識
- アストラルを舞台とする。伝承ではノヴァは災厄と結び付けられている。
- 星環は信仰の象徴として仰がれる。
- 星獣は人々に恐れられており、魔法は社会と文明を支えている。
- 星環教会や王国は秩序に関わる大きな存在。
- 以上は**登場人物たちが受け取っている世界の説明**。本文では必要な時点まで、世界の秘密の正否を先回りして断定しない。

## キャラクターの会話・描写の指針
- **ナハト**：黒髪で刀を使う傭兵。人当たりは悪くなく軽口や皮肉を使う。戦いでは観察、間合い、受け流し、反撃を重視。本心に踏み込まれると距離を取る。
- **ヴォルト**：ナハトの幼馴染の導機術師。読者に近い現実感、ツッコミ、仲間の認識の橋渡しを担う。
- **フレア**：森に縁のある少女。率直で、感じたことの本質を言葉にできる。天然さだけに偏らせない。
- **セレナ**：落ち着いた知性と温かさ、静かな洞察を持つ。優しいだけの受動的な人物にはしない。
- **リヒト**：礼節と責任感を備え、理想を言葉にできる。立場と一人の人間としての思いの両方を描く。

## 執筆時の注意
- 会話で設定を説明させすぎない。
- それぞれの話し方、冗談、沈黙、視線の違いで関係性を見せる。
- 人間関係の発展を急がせず、場面を積み重ねる。
- 魔法の分類・用語・歴史上の結論は、**承認済み原稿の情報開示順**に従う。
- 公開していない真相が必要な作業では、作者から安全に提供された非公開資料を参照する。想像で埋めない。
